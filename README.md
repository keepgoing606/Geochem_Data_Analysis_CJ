# Geochem_Data_Analysis_CJ
# 资源环境大数据工程 - 基础数据分析项目

## 项目简介
本项目基于加拿大萨斯喀彻温省公开的地球化学勘探数据集（3442行，88列），完成从原始数据读取、清洗到可视化分析的全流程。

## 数据处理
- **数据筛选**：从88个字段中筛选出7个核心地球化学指标（纬度、经度、Al、Fe、Ca、Cu、Zn）。
- **缺失值处理**：删除了上述指标中缺失的少量样本（仅个位数）。
- **异常值保留**：在可视化中观察到部分高Al、高Fe数据点。鉴于缺乏野外地质资料佐证，无法判定其为测量误差还是特殊岩性，故保留原始数据，仅在绘图时限制坐标轴范围（xlim/ylim），以突出主体数据相关性。
